# Git vs SVN

## 1. Почему в Git ветвление "дешёвое", а в SVN — "дорогое"?

В Git ветка — это просто указатель на коммит (40-байтный хеш), создаётся мгновенно.
В SVN ветка — это копирование директории на сервере, операция тяжёлая и медленная.

## 2. Можно ли в SVN сделать коммит без интернета?

Нет. SVN — централизованная система: коммит уходит на центральный сервер,
без сети коммит невозможен. В Git коммит делается локально, сеть нужна только для push/pull.

## 3. В каких сценариях SVN может быть предпочтительнее Git?

- Legacy-проекты в госсекторе/банках, где уже настроен SVN и нет смысла мигрировать.
- Очень большие бинарные репозитории (игры, ассеты) — SVN умеет partial checkout.
- Команды с жёстким контролем доступа к отдельным директориям (в SVN это из коробки).
