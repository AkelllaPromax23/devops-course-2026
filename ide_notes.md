# IDE vs CLI для Git

## Удобно в VS Code:
1. Визуальный просмотр diff — сразу видно, что изменилось построчно.
2. Встроенный редактор конфликтов с кнопками "Accept Current/Incoming/Both".
3. GitLens — видно, кто и когда менял каждую строку (blame).

## Удобнее в терминале:
- Interactive rebase (git rebase -i) — в IDE его либо нет, либо он скрыт.
